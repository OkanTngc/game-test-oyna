# Game Test 🏎️

Unity ile yapılmış bir yarış oyunu.

## Nasıl oynanır

1. Sağ taraftaki **Releases** bölümünden en son sürümdeki `GameTest-Windows.zip` dosyasını indir.
2. Zip'e sağ tıkla, **Tümünü ayıkla** de.
3. Çıkan klasördeki **Game Test.exe** dosyasına çift tıkla.
4. Windows mavi bir uyarı (SmartScreen) gösterirse **Daha fazla bilgi → Yine de çalıştır** de.

## Kısayollar

- **Alt + Enter**: Tam ekran / pencere
- **Alt + F4**: Oyundan çık

Sadece Windows'ta çalışır.
